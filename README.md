# Chez Manou : site vitrine

Site public de **Chez Manou Bar-Resto** (depuis 2010) et du **Dépôt Chez Manou** (depuis 1999), Grand-Yoff, Taïba 2, villa 333, Dakar.

Menu, caisses du dépôt, photos, horaires avec statut « ouvert maintenant », et boutons « Commander » qui ouvrent WhatsApp.

Ce site est **100 % statique** : aucune base de données, aucun compte, aucun lien vers l'application de caisse. Même s'il était piraté, il ne donnerait accès à aucune donnée du commerce.

Voir [GUIDE.md](GUIDE.md) pour le mettre en ligne et le modifier.
